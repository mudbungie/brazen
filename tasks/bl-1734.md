v0.0.19 and v0.0.20 published with ZERO assets while all seven `bz <target>` jobs went green: the 'Resolve + check out the release tag' step fell to `git describe --tags --abbrev=0`, which answered v0.0.18 (the job's checkout predates the tag the publish job minted in the same run), so every archive was built from 1d185c4 and re-uploaded onto v0.0.18's Release. Fix: the publish job exports the released tag off release-plz's `releases` JSON output and the binaries job reads it (falling to describe only for the manual backfill with no tag, after a `git fetch --tags --force`). Backfill for v0.0.19/v0.0.20 dispatched by hand (release.md §6 step 4).

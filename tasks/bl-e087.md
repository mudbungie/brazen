Hand audit of the resulting `cargo package --list`, run once as the ball asks. 155 entries, and every one of them accounted for:

9 outside src — Cargo.toml, Cargo.lock, Cargo.toml.orig, .cargo_vcs_info.json (the last two minted by cargo, not tree files), README.md, LICENSE, CHANGELOG.md, SKILL.md, data/defaults.toml. SKILL.md and data/defaults.toml are the two compile-time embeds (include_str! at src/run/discovery.rs and src/config/load.rs); the rest is what the registry renders.

146 under src, all of them .rs, none under src/tests. Nothing else: no specs/ (~500KB design tree), no tests/ or its fixtures, no scripts/ (the gate plus leak-fixtures/, a corpus of deliberately fabricated secrets), no examples/, no .github/.githooks/.claude, no Makefile/AGENTS.md/deny.toml/release-plz.toml.

Two things the old exclude denylist had wrong, both found by the port and both caused by gitignore-style patterns being unanchored:
- `exclude = ["tests", ...]` also matched src/native/tests/, silently dropping two source files from the package. The include list ships them.
- it shipped examples/stdio_transport.rs and release-plz.toml, neither of which is a build input. Both are out now; the README link to the example resolves against the repository.

One subtraction inside src, `!src/tests/**`, and it is proved rather than remembered: that module include_bytes!s tests/fixtures/, which is apparatus and does not ship, so it could not compile from the package; it is 1.4MB, an order of magnitude more than everything else in the tarball put together; and it carries the operator-owned Claude-session recipe verbatim. tests/packaged_files.rs holds it with an invariant instead of a second list — every include_str!/include_bytes! target of every SHIPPED source file must ship too — so re-adding src/tests goes red on the embeds, not on a name someone has to keep in mind. src/testing/ (the test doubles, 40KB, reads nothing outside src) does ship; naming it too would turn the allowlist back into a denylist of module names.

Both directions were driven by hand before landing: adding specs/** to include reddens no_commentary_or_apparatus_ships; removing !src/tests/** reddens every_embed_of_a_shipped_file_ships with the fixture paths it names.
